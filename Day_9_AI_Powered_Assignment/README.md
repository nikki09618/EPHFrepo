# Responsive Personal Portfolio Webpage

This project is a **fully responsive Personal Portfolio Website** built using **HTML and CSS only** (no frameworks). It includes smooth animations, a modern layout, a personal image, and clean navigation optimized for mobile, tablet, and desktop.

---

## 📌 Features

### ✅ **1. Header Section**

* Displays your **name/logo**
* Navigation links: Home, About, Skills, Contact
* Animated hover underline
* Mobile-friendly hamburger menu

### ✅ **2. Hero Section**

* Animated text: **“Hi, I'm Nikita Patel”** (word-by-word fade-in)
* Short description
* Stylish **Contact Me** button
* Profile image with glow animation

### ✅ **3. Skills Section**

* Shows at least **6 skill cards**
* Card hover effects
* Clean grid layout (3-column desktop → 2-column tablet → 1-column mobile)

### ✅ **4. Footer Section**

* Social media icons using image tags
* Contact email
* Copyright text

### 🎨 **Animations Used**

* Word-by-word text fade-in animation
* Image pulse animation
* Button & card hover effects

---

## 📱 Responsiveness

This website is fully responsive across all devices:

### 🖥 Desktop (≥1024px)

* Navigation links displayed in a row
* Skills in 3 columns

### 📟 Tablet (768–1023px)

* Hero text reflows properly
* Image moves above text
* Skills grid becomes 2 columns

### 📱 Mobile (≤767px)

* Hamburger menu appears
* Skills section becomes 1-column
* No horizontal scrolling
